# mebetter-legal

Public legal pages for the MeBetter app (2chiem Studio LLC), served by GitHub Pages at
https://notmechupe.github.io/mebetter-legal/. The app's code lives in a separate private repo.

- `privacy.md` → https://notmechupe.github.io/mebetter-legal/privacy

The app links here through `EXPO_PUBLIC_PRIVACY_URL`. When the policy changes, update its effective
date and keep it in line with `documents/logic/` in the app repo.
